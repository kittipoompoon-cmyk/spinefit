# SpineFit — ออกแบบพนักพิงเก้าอี้เฉพาะบุคคล

เครื่องมือคำนวณเส้นโค้งพนักพิงเก้าอี้จากจุดพิกัดสรีระ 6 จุด ด้วยพหุนามดีกรี 5 (Lagrange Interpolation) หรือ Natural Cubic Spline ต่อยอดจากโครงงานคณิตศาสตร์ "การพัฒนาพนักพิงเก้าอี้ตามแนวสันหลังโค้งด้วย Polynomial Interpolation"

🔗 **ใช้งานได้ที่**: https://kittipoompoon-cmyk.github.io/spinefit/

## ฟีเจอร์

- กรอกพิกัดสรีระเองหรือเลือกจากข้อมูลมาตรฐาน 16 กลุ่ม (8 ช่วงอายุ × 2 เพศ)
- คำนวณเส้นโค้งด้วย Lagrange Interpolation ดีกรี 5 หรือ Natural Cubic Spline
- ตรวจจับ Runge's Phenomenon อัตโนมัติ
- กราฟ 2 มิติ และโมเดล 3 มิติแบบหมุนได้ (Three.js)
- วิเคราะห์มุมเอียง, จำแนกขนาดเก้าอี้ S/M/L, ตรวจสอบมาตรฐาน ANSI
- ส่งออกพิกัดเป็น CSV
- แบบประเมินความเสี่ยงด้านการยศาสตร์ (ไม่ใช่เครื่องมือวินิจฉัยทางการแพทย์)

## การพัฒนา

โปรเจกต์นี้เป็นไฟล์ HTML/CSS/JS เดี่ยว ไม่มี build step — เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง หรือใช้ Live Server extension ใน VS Code เพื่อดูผลแบบ auto-reload

## เทคโนโลยี

- Vanilla JavaScript (ไม่มี framework)
- Three.js (โหลดแบบ lazy จาก CDN) สำหรับโมเดล 3 มิติ
- ไม่มี backend / ไม่มีการเก็บข้อมูลผู้ใช้
